# Ancient Fantasia
Built around Ancient Empires II, and then expanded. A fantasy world~

This is the earliest version of Fantasia (before expanded to include almost all modern warfare -as modern arcanepunk mod), with some changes:
- Available Civilizations, instead add other faction that is not icluded in the main mod Fantasia
- City-state bonuses, since now it is possible for each CS grants different bonuses, why not?
- AI personalities, add it so AI pursue victory through different path
- Golems skills/promotions, changed from the old one, utilize available mechanism
- Mage units, instead of just support (medic), now become military
- Mage/dragon now has access to elemental skills, enable their attack to inflict status ailments
- Tamer, was not added until the main mod Fantasia updated as modern arcanepunk mod
- Monster overhaul, with some also inflicts status ailment
- Ideologies removed
- Religion removed, now Faith only to buy Hero and Great Person
- Scientific Victory changed to match now WIP fts-beta
